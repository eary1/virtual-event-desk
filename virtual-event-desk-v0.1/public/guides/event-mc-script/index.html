VRChatイベント司会台本の作り方｜90分交流会の進行例と60分版アレンジ

VRChat交流イベントの司会で何を話すか迷った人向けに、90分の進行表と開会・自己紹介・休憩・閉会のセリフ例を紹介。時間が押したときの対応もまとめます。

VRChat交流イベントの司会で何を話すか迷った人向けに、90分の進行表と開会・自己紹介・休憩・閉会のセリフ例を紹介。時間が押したときの対応もまとめます。

司会台本は「何を話すか」と「何分使うか」をセットで決める

イベントの司会で困りがちなのは、次の企画へ移る言葉が出てこないことと、思ったより時間が押してしまうことです。台本にはセリフだけでなく、開始時刻、担当、終了の目安を書いておくと進めやすくなります。

ここでは参加者20人程度・スタッフ3人の交流会を仮定します。これは編集上の例であり、VRChatが推奨する人数や公式の進行方法ではありません。

  • 各場面に開始時刻を付ける
  • 説明の言葉は短く、初参加者にも伝わる表現にする
  • 沈黙が生まれたときの質問を2つほど準備
  • 遅延した場合に短縮する企画を決める
  • 問題が起きた場合に司会が誰へ引き継ぐか書く

90分交流会の進行例（20:00〜21:30）

20:00〜20:10（10分）開会・参加方法と注意事項の案内
20:10〜20:20（10分）簡単な自己紹介とアイスブレイク
20:20〜20:55（35分）メイン交流企画
20:55〜21:05（10分）休憩・進行調整
21:05〜21:20（15分）後半交流・自由参加企画
21:20〜21:30（10分）閉会・次回案内・退出
合計90分

受付やスタッフの動作確認は、上記の90分とは別に開催前の時間を確保します。会場の読み込みや参加者の移動に時間がかかる場合は、休憩や予備時間を増やして調整しましょう。

開会（20:00）｜最初の30〜60秒で伝える例文

「みなさん、こんばんは！本日は【イベント名】に来てくださってありがとうございます。司会の【名前】です。今日は【内容】を中心に、【終了予定時刻】まで一緒に楽しみましょう。初参加の方や、話すより聞くほうが好きな方も歓迎です。参加方法や困ったときの連絡先は【スタッフ名・連絡方法】です。撮影・配信については【事前に決めたルール】に従ってください。それでは始めます！」

読み上げる前に、イベント名・終了時刻・撮影ルール・連絡先を具体的な内容に置き換えます。音声を聞けない参加者のため、重要事項をテキストでも案内できると親切です。

自己紹介（20:10）｜発言を強制しない進め方

「最初に短い自己紹介をお願いします。お名前と、最近好きなワールドや遊びを一つ教えてください。話したくない方はパスでも大丈夫です。では私から始めますね」

20人全員が1分ずつ話すと20分を超えてしまいます。全員の自己紹介をする場合は30秒程度を目安にするか、少人数のグループに分けるなど、最初から時間に収まる形を選びましょう。誰かが答えられなくても責めず、司会が次の人へ自然につなぎます。

  • 短い質問例：「最近行って楽しかったワールドは？」
  • 話しづらい人向け：「聞いているだけでも大丈夫です」
  • 時間が足りないとき：「続きは後半の交流時間で話しましょう」

メイン企画への移行（20:20）｜手順を3つに分けて説明

「ここからは【企画名】です。①【最初の動作】、②【次の動作】、③【終わり方】の順番で進みます。途中で分からなくなったら、スタッフの【名前】へ声をかけてください。それでは始めます！」

イベント中に長いルール説明をすると混乱しやすいため、まずは3つの動作に要約してから詳しい話を追加します。ワールドのギミックを使う場合は、参加者の使用環境に応じて事前に操作確認しましょう。

休憩（20:55）｜再集合時刻を必ず伝える

「ここで10分間の休憩に入ります。【21:05】に同じ場所へ集合してください。戻ってきたら後半を始めます。困ったことがあれば【受付担当】までお願いします」

休憩に入ると参加者が別の場所へ移動することがあります。再集合の時刻と場所を明示し、変更があれば同じ連絡手段でも案内しましょう。

後半・終了（21:05〜21:30）｜締めの例文

「後半は【内容】を楽しみましょう。残り時間は15分ほどです。途中退出する方は、そのまま抜けていただいて大丈夫です」

「そろそろ終了のお時間です。本日は【イベント名】に参加していただきありがとうございました。次回のお知らせは【告知先】でご案内します。気になった点や改善してほしい点があれば【連絡先】へどうぞ。これで閉会です。お疲れさまでした！」

集合写真を撮る場合は、撮影することと公開するかどうかを事前に案内し、参加者の意向と当該ワールドのルールを尊重してください。

60分に短縮する場合の時間割

開始から5分：開会・注意事項
次の10分：自己紹介（または小グループ交流）
次の30分：メイン企画
次の5分：休憩・調整
次の5分：後半交流
最後の5分：閉会
合計60分

初めての開催で60分に収めたい場合は、企画を増やすよりも一つのメイン企画に集中すると組み立てやすくなります。自己紹介に全員参加を求めない形式なら、時間を調整しやすくなります。

予定が押したときと、トラブルが起きたときのセリフ

【予定が10分遅れたら】「進行が少し遅れているため、後半の内容を短くして予定時刻に終了します。ご協力ありがとうございます」

【音声やワールドの問題が起きたら】「いまスタッフが状況を確認しています。少し進行を止めますので、お待ちください。移動が必要な場合は連絡方法をご案内します」

【参加者の安全に関する問題が起きたら】「運営確認のため、いったん進行を中断します。案内があるまで無理に移動せず、必要なら安全な場所へ移動してください」。状況に応じて公開の場で詳細を説明せず、権限を持つ担当者へ引き継ぎます。

VRChatのインスタンスの種類やグループのモデレーション権限には差があるため、スタッフなら必ず参加者を管理できると考えないでください。安全機能や正式な報告方法は公式案内で確認してください。

開催前の読み合わせチェックと次の準備

開催前に少なくとも一度、司会・受付・安全担当で台本を通して読み合わせましょう。特に見直したいのは「説明が長すぎないか」「時間が押したときに何を削るか」「途中参加者を誰が案内するか」「予定時刻に閉会できるか」の4点です。

無料のイベント準備プランナー（/planner/）では、イベントの種類・時間・人数から基本的な進行表やチェックリストを作れます。さらに編集用台本やスタッフマニュアルをまとめて使いたい場合は、有料の運営スターターキット（/kit/）も選択肢です。購入前に商品内容を確認してください。

  • 開始・終了時刻が告知と一致している
  • 司会と受付の担当が決まっている
  • 参加方法とトラブル時の連絡先が共有されている
  • 撮影・配信のルールを案内できる
  • 予備の会場や代役が必要か検討した
