    確認チェックリスト

    AIの自動審査とは別に、必ず人間が内容と根拠を確認してください。

    GitHubで承認・公開準備 →

    すべてのチェックを完了するとGitHubへのリンクを使用できます。

    承認した後の流れ
    1. GitHubにログインし、「Run workflow」をクリック。
    2. Branchを main にし、記事IDを入力。
    3. 確認内容に対応する3つのチェックを有効にして実行。
    4. 完了ログの「Compare & pull request」から変更を確認してプルリクエストを作成。
    5. 最終的にマージして初めて公開サイトに反映されます。

    この手順はGitHubのアカウント権限で保護されています。ここでチェックした値はGitHubには送信されません。
