運営情報・プライバシー

サービスの位置づけと、入力データの取り扱いについて説明します。

サイトについて

「バーチャルイベント準備室」は、VRChatなどで開催する交流イベントの準備を支援する非公式の試作サイトです。VRChat Inc.その他のプラットフォーム運営会社と提携・協賛・公式関係はありません。

イベント準備ツールの入力情報

イベント名、開催日、人数、会場名などの入力内容は、ブラウザ上のJavaScriptのみで計算に使います。イベント準備ツールへの入力内容は、サイトのサーバーへ送信・保存しません。入力した内容と生成結果はページを更新すると初期状態に戻ります。なお、ページのアクセス情報の計測については下記をご確認ください。

「テキスト保存」機能を使った場合は、ユーザー自身の端末にテキストファイルが作成されます。コピー機能は端末のクリップボードを利用します。

アクセス解析・広告

トップページにはCloudflare Web Analyticsの計測タグを設置し、ページ閲覧状況などを把握しています。計測に際してCloudflareへページアクセスに関する情報が送信されます。イベント準備ツールの入力内容はアクセス解析に送信しません。現時点で広告配信・アフィリエイトリンクは導入していません。

商品販売

運営スターターキットの紹介ページから、外部のBOOTH商品ページへ移動できます。価格は980円で、購入・決済・ダウンロード・返金・お問い合わせなどの販売に関する手続きはBOOTH上で行われます。購入前にBOOTHに掲載されている商品情報・利用条件をご確認ください。

免責事項

表示される進行表やチェックリストは一般的な参考例です。各ワールドやコミュニティの状況に合わせて調整してください。掲載内容は正確性に努めていますが、プラットフォームの最新の仕様や安全ルールは公式資料で確認してください。

お問い合わせ・運営者情報

商品に関するお問い合わせは、BOOTHの商品ページまたはショップのメッセージ機能をご利用ください。サイト運営情報・販売者情報はBOOTHのショップページに掲載する内容もご確認ください。
